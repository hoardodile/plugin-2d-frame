# 2D 帧动画 · 精灵帧动画演示

在 hoardodile 里播放**已导出的 2D 角色目录**：按帧播放、动作切换、按帧触发的角色音频。

角色是 2D 精灵帧动画（五层精灵换帧曲线 + 位移/缩放/旋转，30 fps，约 150 张精灵、
约 75 个动作）。导出格式见 `docs/format.md`；导出工具是另一个私有项目，不在本仓库内。

## 功能

- 识别两类资源：**单个自包含角色目录**（根目录含 `character.json`，可单独保留/
  删除）与**合集根目录**（含 `catalog.json`，带角色选择器）。
- **预览（默认）**：一屏同时播放该角色的**全部动作**，无需任何设置。每个动作一块，
  按「全帧包围盒」和选定的显示比例定尺寸；块用 flex 自动
  换行排布，放不下就纵向滚动。预览**完全无声**（不加载音频映射，也没有任何播放路径）。
- **检视**：动作密表（搜索、分类筛选，每行帧数/毫秒/音效事件数）、以选定尺寸为上限的
  画布（动作用整帧包围盒放进画布，只缩不放）、可点选定位的**帧条**（真实帧缩略图 + 播放头）；
  右侧面板顶部是 **Loop / 自动下一个 / Sound 三个开关（各占一行）**，往下是当前帧信息：
  帧号与毫秒、本帧绘制的层（层/精灵/位置/缩放/
  旋转）、本帧音效事件、精灵与图集信息（事件映射收进按钮弹出的对话框）。「自动下一个」
  一次只播一个动作，播完立刻切到列表里的下一个（最后一个之后回到第一个），并把
  Loop 开关关掉、置灰（循环的时钟永远到不了动作结尾）。左右两个侧栏按
  窗口宽度自动显隐（≥1150 显示左侧动作表，≥1440 再显示右侧面板）。
- **设置会被记住**：当前视图（预览/检视）与检视里的三个开关都是**插件偏好**，写进宿主
  偏好存储——首次打开是预览，之后回到上次离开的地方，重开、换角色、换合集都保持。
- **底部控制栏（两种模式一致）**：播放/暂停、重播、实时读数（预览显示动作数，检视显示
  `第 N / M 帧 · 毫秒`）、最右侧的查看模式切换；合集资源再多一个带搜索的角色选择器。
  **缩小显示**默认开启并会记住设置，按每段动作的建议比例显示；关闭后恢复原尺寸。
  没有建议比例的旧数据保持原尺寸。切换显示大小不改变动作、帧率或声音时间轴。
- 角色音频：按帧列出导出数据里的音效事件（音量一并还原，非 1.0 显示 `x0.80` 角标），
  可播放已解析样本，并显示事件→样本的解析状态（未解析会明确标注）。
- 卡片：`cover.png` 作为封面；左下角标是「动作图标 + 动作数」和「音效图标 + 音效事件数」
  两个图标组合（合集资源换成角色数），右下角标是封面的原始像素尺寸。
- 权限：`sourceMeta`（其余保持默认关闭）。

## 要求

- hoardodile ≥ 0.2.0。
- 一个已导出的角色目录或合集目录；插件本身不附带任何数据。
- 安装前请确认信任该仓库——插件代码在受限沙箱中作为服务端代码运行。
