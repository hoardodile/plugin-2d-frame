# 2D Frame — スプライトアニメーションビューア

**書き出し済みの 2D キャラクターフォルダ**を hoardodile 上で再生します：
フレーム単位の再生、アクション切り替え、フレームに紐づくキャラクター音声。

キャラクターは 2D スプライトアニメーションです（5 レイヤーの差し替えカーブ +
位置/拡大縮小/回転、30 fps、1 キャラあたり約 150 スプライト・約 75 アクション）。
書き出し形式は `docs/format.md` を参照。書き出しツール自体は別の非公開プロジェクトで、
このリポジトリには含まれません。

## 機能

- 2 種類のリソースを認識：`character.json` を含む**自己完結したキャラクター
  フォルダ**（個別に保持・削除できる）と、`catalog.json` を含む**コレクション
  ルート**（キャラクター選択付き）。
- **プレビュー（既定）**：そのキャラクターの**全アクションを同時に再生**します。設定は
  不要で、1 アクション = 1 タイル。タイルは全フレームの外接矩形に合わせて寸法を決め、
  元のサイズ、または設定に応じた推奨縮小サイズで表示します。
  タイルは flex で折り返すので、大きさの違うアクションがそれぞれの場所に収まり、入りきらない
  場合は縦スクロールします。プレビューは**音声を出しません**（音声マップを読み込まず、
  再生経路もありません）。
- **検証**：アクションの高密度テーブル（検索・カテゴリ絞り込み、行ごとにフレーム数 /
  ミリ秒 / 効果音イベント数）、選択した表示サイズを上限とするステージ（アニメーションの外接矩形を画布に
  収め、切り取りません）、実フレームのサムネイルを並べた
  **フレームストリップ**（クリックでシーク、再生ヘッド強調）。右パネルの先頭は **Loop /
  次のアクション / Sound のスイッチ（1 行ずつ）**、続いて現在フレームの情報（層 /
  スプライト / 位置 / 拡大 /
  回転、そのフレームで鳴る音声、スプライトとアトラス）。「次のアクション」は 1 アクションを
  再生し終えるとリストの次へ移り（最後の次は最初へ戻る）、Loop を切り、そのスイッチを
  無効化します（ループする時計はアクションの終端に到達しないため）。イベント対応表はボタン
  から開くダイアログにあります。左右のパネルはウィンドウ幅に追従します（1150 px 以上で左、
  1440 px 以上で右）。
- **設定は記憶されます**：開いているビュー（プレビュー / 検証）と検証側の 3 つのスイッチは
  **プラグイン設定**としてホストの設定ストアに保存されます。初回はプレビューで開き、
  以降は前回の場所から始まります（再読み込み・別キャラクター・コレクションをまたいで保持）。
- **下部コントロールバー（両モード共通）**：再生/一時停止、リスタート、ライブ表示
  （プレビューはアクション数、検証は `フレーム N / M · ミリ秒`）、右端に表示モードの切替。
  コレクションでは検索付きのキャラクター選択も並びます。「縮小表示」は既定でオンで、
  設定は記憶されます。推奨倍率のないデータは原寸のままです。オフにすると元のサイズに戻り、
  再生や音声のタイミングは変わりません。
- キャラクター音声：書き出しデータがフレームごとに発火する音声イベントを一覧表示し、
  書き出された音量も復元（1.0 以外は `x0.80` バッジ）。サンプルに解決できたものは
  再生可能で、未解決も明示。
- カード：`cover.png` をカバーに。左下バッジはアクションのアイコン＋アクション数と、
  サウンドのアイコン＋音声イベント数（コレクションではキャラクター数に切り替わります）。
  右下バッジはカバーの原寸ピクセルサイズです。

## 要件

- hoardodile ≥ 0.2.0。
- 書き出し済みのキャラクターフォルダまたはコレクション。プラグインにデータは
  同梱されません。
- インストール前にリポジトリを信頼してください——プラグインコードは制限付き
  サンドボックス内のサーバー側コードとして実行されます。
